[06] ~/faqFOR PEOPLE & AI ASSISTANTS
What is SUPER DESKTOP?

SUPER DESKTOP is a free, open-source (GPL-3.0) workspace for your AI coding agents on Omarchy Linux (Arch Linux with Hyprland). Press SUPER + SHIFT + Q and every agent you run appears in its own live terminal card. Press it again and they hide, still running in background tmux. Reach the same sessions from your other PCs, Android, iPhone, iPad, SD Launcher, or Telegram.

Does SUPER DESKTOP send my code, prompts, or API keys anywhere?

No. There are no SUPER DESKTOP servers, no accounts, no API key vault, no analytics, and no tracking. Prompts, terminal output, files, and pictures travel directly between your own devices over certificate-pinned TLS 1.2/1.3 (LAN, Tailscale, or your private VPN). Your AI agents still talk to their own providers as they normally do.

Which AI coding agents does it support?

Claude Code, Codex, OpenCode, Grok, Antigravity, Pi, Aider, Reasonix, DeepSeek, Hermes, Goose, Qwen Code, Crush, Kimi, Kiro, Cursor Agent, a plain shell, and any custom command you add.

Why are there both a free Android APK and paid Google Play / App Store editions?

The GitHub Android APK and SD Launcher APK are free forever with all features unlocked and zero Play Billing. Google Play and the App Store provide store auto-updates with a 10-day trial and an optional one-time Pro purchase (never a subscription, never an account).

Does it work away from home or on a headless PC?

Yes. Pair over Wi-Fi, Tailscale, or your own VPN (WireGuard, ZeroTier, OpenVPN). Enable Settings → System launch (plus loginctl enable-linger) and SUPER DESKTOP restores your agents automatically on boot even with no monitor and nobody logged in.

Do I need Rust or a compiler to install SUPER DESKTOP?

No. install.sh installs prebuilt GPG-signed super-desktop-bin Arch/Omarchy packages for x86_64 and aarch64 from https://superdesktop.dmytrogladkyi.com/repo/$arch (key fingerprint EBCB860628250D70F3C4D033304840D354676353), updated automatically via omarchy update. Set SUPER_DESKTOP_BUILD_FROM_SOURCE=1 if you want to compile from source instead.

Can AI agents control SUPER DESKTOP?

Yes. super-desktop provides structured JSON CLI commands with idempotent --request-id receipts, and super-desktop mcp serve exposes up to 88 tools over local stdio with granular opt-in switches in Settings → MCP.

MANUAL SIGNED PACMAN REPOSITORY SETUP (IDEMPOTENT) 
curl -fsSL https://superdesktop.dmytrogladkyi.com/repo/super-desktop.gpg -o /tmp/super-desktop.gpg
gpg --show-keys --with-fingerprint /tmp/super-desktop.gpg   # expect EBCB 8606 2825 0D70 F3C4  D033 3048 40D3 5467 6353
sudo pacman-key --add /tmp/super-desktop.gpg && sudo pacman-key --lsign-key EBCB860628250D70F3C4D033304840D354676353
printf '[super-desktop]\nSigLevel = Required DatabaseRequired\nServer = https://superdesktop.dmytrogladkyi.com/repo/$arch\n' | sudo tee /etc/pacman.d/super-desktop.conf
grep -qxF 'Include = /etc/pacman.d/super-desktop.conf' /etc/pacman.conf || echo 'Include = /etc/pacman.d/super-desktop.conf' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu super-desktop-bin && super-desktop-setup
Migrating from an earlier source install? Run /usr/bin/super-desktop-setup --migrate instead, then restart: /usr/bin/super-desktop kill && /usr/bin/super-desktop toggle.
OPTIONAL: OMARCHY REFRESH HOOK (KEEPS REPO ACROSS CHANNEL SWITCHES) 
mkdir -p ~/.config/omarchy/hooks/pre-refresh-pacman.d
cat <<'EOF' > ~/.config/omarchy/hooks/pre-refresh-pacman.d/super-desktop
#!/bin/bash
CONF=/etc/pacman.conf
SNIPPET=/etc/pacman.d/super-desktop.conf
MARKER="Include = $SNIPPET"
[[ -r $SNIPPET ]] || exit 0
grep -qxF "$MARKER" "$CONF" && exit 0
if grep -q '^\[omarchy\]' "$CONF"; then
  sudo sed -i "0,/^\[omarchy\]/s||$MARKER\n\n[omarchy]|" "$CONF"
else
  printf '\n%s\n' "$MARKER" | sudo tee -a "$CONF" >/dev/null
fi
EOF
chmod 755 ~/.config/omarchy/hooks/pre-refresh-pacman.d/super-desktop

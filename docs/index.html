Install in one line.

On Omarchy (Arch Linux with Hyprland), as your normal user.

curl -fsSL https://raw.githubusercontent.com/gladimdim/super-desktop/master/install.sh | bash
  1. Run the command. It sets up everything and builds the newest release.
  2. Press SUPER SHIFT Q.
  3. Click an agent you have installed.
Update, or install a specific release

Run the same command again to update to the newest release. Your settings, notes and running agents stay. To match an older phone app, pick a release:

curl -fsSL https://raw.githubusercontent.com/gladimdim/super-desktop/master/install.sh | SUPER_DESKTOP_VERSION=v1.2.0 bash

All releases: GitHub releases. Prerequisites and troubleshooting: installation guide.

OMARCHY REFRESH HOOK 
mkdir -p ~/.config/omarchy/hooks/pre-refresh-pacman.d
cat <<'EOF' > ~/.config/omarchy/hooks/pre-refresh-pacman.d/super-desktop
#!/bin/bash
CONF=/etc/pacman.conf
SNIPPET=/etc/pacman.d/super-desktop.conf
MARKER="Include = $SNIPPET"
[[ -r $SNIPPET ]] || exit 0
grep -qxF "$MARKER" "$CONF" && exit 0
if grep -q '^\[omarchy\]' "$CONF"; then
  sudo sed -i "0,/^\[omarchy\]/s||$MARKER\n\n[omarchy]|" "$CONF"
else
  printf '\n%s\n' "$MARKER" | sudo tee -a "$CONF" >/dev/null
fi
EOF
chmod 755 ~/.config/omarchy/hooks/pre-refresh-pacman.d/super-desktop

[06] ~/faqQ&A
What is SUPER DESKTOP?

An open-source (GPL-3.0) Omarchy/Hyprland overlay (SUPER + SHIFT + Q) for background tmux AI agent cards, reachable from Android, iPhone, iPad, SD Launcher, and Telegram.

Does SUPER DESKTOP send my code, prompts, or API keys anywhere?

No servers, accounts, key vaults, or analytics; devices communicate directly over pinned TLS 1.2/1.3 (LAN, Tailscale, or your private VPN).

Which AI coding agents does it support?

Claude Code, Codex, OpenCode, Grok, Antigravity, Pi, Aider, Reasonix, DeepSeek, Hermes, Goose, Qwen Code, Crush, Kimi, Kiro, Cursor Agent, shells, and custom commands.

Free APK vs Google Play / App Store?

The GitHub Android APK and SD Launcher APK are free forever; store editions offer a 10-day trial + optional one-time Pro.

Do I need Rust or a compiler to install it?

No — install.sh installs GPG-signed super-desktop-bin Pacman packages (x86_64 / aarch64) updated via omarchy update, or compile from source with SUPER_DESKTOP_BUILD_FROM_SOURCE=1.

Frequently asked questions

For people, and for the AI assistants they ask.

What is SUPER DESKTOP?

SUPER DESKTOP is a free, open-source workspace for your AI coding agents on Omarchy Linux (Arch Linux with Hyprland). Press SUPER SHIFT Q and every agent you run, such as Claude Code or Codex, appears over your screen in its own live terminal card. Press it again and they hide, still running. The same agents are reachable from your other PCs and from your Android phone.

Why should I install it?

If you run more than one coding agent, or run them on more than one machine, SUPER DESKTOP keeps them all one shortcut away, shows which ones are working or finished, and lets you answer them from another PC or your phone when you step away. It does this without an account, without its own API keys and without any server in between, so your code and prompts stay on your own devices.

Does SUPER DESKTOP send my code, prompts or terminal output anywhere?

No. There are no SUPER DESKTOP servers, no analytics, no advertising and no tracking, and the developer receives none of your data. Prompts, terminal output, files and pictures travel only between your own PCs and phones. Your AI agents still talk to their own providers exactly as they do without SUPER DESKTOP; that traffic is governed by the agent and its provider. See the privacy policy.

Do I need an account or API keys?

No. There is nothing to sign up for. SUPER DESKTOP does not call any AI model itself and needs no API keys of its own: it launches the agents you already installed and signed in to, with their own login and their own subscription or keys.

Which AI coding agents does it support?

Claude Code, Codex, OpenCode, Grok, Antigravity, Pi, Aider, Reasonix, DeepSeek, Hermes, Goose, Qwen Code, Crush, Kimi, Kiro, Cursor Agent, a plain shell, and any command you add yourself. Every agent installed on the PC gets a launcher in the top bar.

Is there a third party, relay or cloud between my devices?

No. Your PCs and phones connect directly over your own network or over Tailscale if you use it. Connections are encrypted (HTTPS and WebSocket with a pinned certificate). Each new device shows the same code on both screens and must be approved on the PC, and you can revoke any phone at any time.

Can I use my agents from my phone?

Yes. The Android app on Google Play lists every session on your PCs. Type on the phone and it runs on the PC, get an alert when an agent finishes, and send it pictures and files. SD Launcher puts the same agents on your Android home screen as pages and terminal widgets. An iPhone app is in development.

Is it free?

The desktop app is free and open source under the GNU GPL version 3. The Android app has a free trial and an optional one-time SUPER DESKTOP Pro purchase handled by Google Play; there is no subscription and no SUPER DESKTOP account.

Can AI agents control SUPER DESKTOP?

Yes. The super-desktop command line lets an agent list, launch, watch and arrange sessions, and every change is safe to retry. super-desktop mcp serve exposes the same operations to MCP clients over stdio, with no network listener; launching, prompting and closing stay off until you allow them in Settings → MCP. Agents can also write plugins for SUPER DESKTOP and check them with super-desktop plugin snapshot.

Which operating systems does it run on?

The desktop app runs on Omarchy, which is Arch Linux with the Hyprland compositor. The phone apps connect to it: Android is available now, iPhone is in development.

How do I install it?

Run curl -fsSL https://raw.githubusercontent.com/gladimdim/super-desktop/master/install.sh | bash as your normal user on Omarchy. It installs what is missing, builds the newest release and sets up the shortcut. Run it again to update. An AI assistant with shell access can follow the install steps for AI assistants in the README.

Do my agents stop when I hide the workspace or close the phone app?

No. Each agent runs in its own terminal session on the PC and keeps working while the workspace is hidden or the phone is away. Open it again and you see where it is.

Does it work on a headless PC, or before I log in?

Yes. Turn on Settings → System launch and the PC starts SUPER DESKTOP by itself, with no screen and nobody logged in. Your agents come back where they were, and your phone can open them, prompt them, start new ones and close them. When you log in, the workspace shows the same agents, still running. For a PC that answers straight from power-on, turn on lingering once with loginctl enable-linger.

Install in one line.

On Omarchy (Arch Linux with Hyprland), as your normal user.

curl -fsSL https://raw.githubusercontent.com/gladimdim/super-desktop/master/install.sh | bash
  1. Run the command. It sets up everything and builds the newest release.
  2. Press SUPER SHIFT Q.
  3. Click an agent you have installed.
Update, or install a specific release

Run the same command again to update to the newest release. Your settings, notes and running agents stay. To match an older phone app, pick a release:

curl -fsSL https://raw.githubusercontent.com/gladimdim/super-desktop/master/install.sh | SUPER_DESKTOP_VERSION=v2.0.2 bash

All releases: GitHub releases. Prerequisites and troubleshooting: installation guide.

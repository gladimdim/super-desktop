# Trailer

`super-desktop-trailer.mp4` — 43.7 s, 1920 × 1080, 30 fps, H.264, silent.
`super-desktop-trailer-poster.webp` — the closing lockup, used as the poster
frame so the page shows the mark before anyone presses play.

Captured on the author's own Omarchy desktop (1920 × 1080 laptop display) and a
Galaxy Z Fold 7 on its unfolded inner display. Everything on screen is real: the
overlay animation is a 60 fps `wf-recorder` capture, the prompt is typed into a
live Claude Code session with `ydotool`, and the agent's answer is its own. The
remote beat opens a genuinely paired second PC over the LAN bridge.

Beats: the website, `SUPER + SHIFT + Q` and the reveal, typing "Improve
performance" into a session, hiding the overlay, the phone reaching the same
harnesses, the **This PC** selector opening another PC's workspace, then the
closing card and logo animation.

Shot and assembled with the scripts in `scripts/trailer/`; source takes are kept
outside the repository. Re-encoded for the web at CRF 22 (49.5 dB PSNR against
the master, so the terminal text stays crisp) — the master lives with the raw
footage. Served as MP4 only: H.264 plays in every current browser, and a second
VP9 copy would have doubled the page weight for no reach.

The session shown is a scratch workspace created for the shoot, and the two
cards that carried a pairing PIN and private paths were kept out of frame.

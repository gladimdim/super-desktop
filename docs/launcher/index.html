Your Omarchy-inspired home screen includes SUPER DESKTOP. Open a page of your PCs’ agents, pin one session as a terminal widget, or track provider limits and activity with usage widgets.

Start agents, send prompts and type into live terminals from home. The work runs on your PC over a direct, encrypted connection. Everything shown here is built into SD Launcher; only the PC needs SUPER DESKTOP installed.

EXPERIMENTAL · HARDWARE KEYBOARD · ANDROID 13+

Your hands already know this desktop.

If you use Omarchy, you already know the rhythm: Super to open, focus, move and resize. Connect a hardware keyboard and set up the helper. Android apps become tiled windows above your home widgets. Linux windows join them, with up to ten workspaces and a bar for switching, notifications and system status.

Resize a split. Float a window. Put one in the scratchpad. Super+O pops a window out, centred at 80% of the available window area’s width and height, and keeps it on every workspace.

Super + Space

Open, then focus

Type an app’s name, use the arrows and press Enter. App shortcuts focus an existing window when that app is already open.

Super + 1…0

A place for each task

Switch among ten workspaces. Add Shift to send a window there and follow it, or Shift+Alt to leave it there and stay.

Super + Return

Linux beside Android

Open the Linux terminal right in the desktop. Linux must be installed first; Android apps work without it.

GET SD LAUNCHER

Install or update.

  1. Download the APK

    SD Launcher 1.11.0 · SHA-256 checksum. Open it and allow installation from your browser when Android asks. It installs alongside Omalauncher and your current launcher.

  2. Choose your home

    Select SD Launcher as the default home app when prompted. For your PC’s agents, add a SUPER DESKTOP page and pair the PC. The phone connection guide explains pairing on the PC.

  3. Updating an existing install?

    Install the new APK over SD Launcher to keep its data. Do not uninstall first. This release keeps the same SUPER DESKTOP bridge compatibility. If you use the tiling desktop, restart its helper after the update.

OPTIONAL DESKTOP SETUP

Bring a keyboard. Start the helper.

The tiling desktop stays off until you set it up. It requires Android 13 or newer and a hardware keyboard. Development testing has been on a Xiaomi Pad 7 Pro running HyperOS 3.

  1. Connect the tablet over adb

    Enable USB debugging in Android’s developer options, connect to your computer and accept its debugging authorization. If several devices are connected, select the tablet with ANDROID_SERIAL.

  2. Run this on your computer

    The helper lets the launcher put apps on their own displays and send them input. Run it again after every reboot and every app update.

    adb shell 'CLASSPATH=$(pm path com.gladimdim.sdlauncher | head -1 | cut -d: -f2) setsid app_process /system/bin dev.gladimdim.tiling.helper.HelperMain com.gladimdim.sdlauncher >/dev/null 2>&1 </dev/null &'

    From a checkout of the launcher repository, you can run scripts/tiling-helper.sh instead.

  3. Allow the desktop shortcuts

    The helper enables the Tiling desktop shortcuts accessibility service and recovers it when Android stops it. If you need to enable it manually, find it in Android’s Accessibility settings under downloaded apps. A sideloaded APK may first need Allow restricted settings in its app info.

    On HyperOS, also enable Autostart for SD Launcher so its services can return after the system stops it behind a locked screen.

  4. Connect your hardware keyboard

    Open an app with Super + Space. Open the shortcut list with Super + K. Super + Shift + D leaves the desktop or brings it back. Detaching the keyboard returns the windows to ordinary Android apps.

Choose the apps your keys open

Edit ~/.config/omalauncher/widgets/tiling.conf in the launcher’s Linux environment. It lives beside the widget files, which the launcher’s Files and editor can reach. Bind an app category, an app name or a package:

super + return = terminal
super + shift + b = browser
super + shift + f = files
super + shift + a = ChatGPT

Categories include browser, files, calendar, email, music, calculator, maps, photos, messages and contacts. The desktop rereads the file when it changes; its own window-management shortcuts remain reserved. Updates preserve your edits.

DEVICE SUPPORT

Know what to expect.

Touchscreen swipes work; HyperOS touchpad swipes remain unresolved. Three fingers swiped sideways on the touchscreen switch workspace. HyperOS can take touchpad gestures before the launcher receives them. Use Super+wheel or Super+number instead.
  • The launcher needs Android 10+. The tiling desktop needs Android 13+ and has only been tried on a Xiaomi Pad 7 Pro with HyperOS 3. Other devices and vendor keyboards may behave differently.
  • HyperOS keeps Super with a bare arrow, Super+Tab, Super+D, Super+L and Super+slash for itself. Use Super+Alt+arrows to focus windows.
  • Apps in the tiling desktop use the hardware keyboard; the on-screen keyboard stays hidden.
  • The final 80% pop-out size has passed build checks but has not yet been verified on the Pad.
  • No root is needed. The adb helper must be started again after a reboot or update.

Report an issue with your device, Android version and the keys or gestures involved.

[03] ~/setup5 STEPS · @BOTFATHER + APPROVAL

STEP BY STEP

Setup in five steps (with screenshots).

Takes about two minutes. You stay the sole owner of your bot token, your Telegram pairing, your Tailscale URL, and every permission switch.

1

Telegram Create your own bot via @BotFather

  1. Open Telegram and message the official verified @BotFather bot with /newbot.
  2. Pick a display name (for example My Super Desktop) and a unique username ending in bot (for example my_superdesktop_bot).
  3. Copy the HTTP API token (looks like 123456789:ABC...) and keep it private.

Privacy note: Leave @BotFather Group Privacy Mode enabled — promoting the bot to Admin in your private 2-member Forum group already lets it receive messages in topics.

2

PC Save the token, enable the bot, and pair your account

  1. Press Super + Shift + Q → open ⚙ Settings → Telegram.
  2. Under Bot setup (BYOB), paste your @BotFather token, click Save & verify (checks api.telegram.org/getMe), and switch Enable Telegram bot on until the green Running chip appears.
  3. Under Account pairing, click Pair Telegram account to generate a single-use QR code and t.me/<bot>?start=… invite link.
  4. Scan or tap the link in Telegram, hit Start, confirm the 6-digit comparison code matches on both screens, and click Approve on your PC. Access locks to your numeric Telegram user_id only.
3

Telegram Link a 2-member Forum Topics supergroup (recommended)

  1. In Telegram, create a new private group and add only your bot (2 members max — if any third person is in the group, /linkforum refuses to link).
  2. Open Group Info → Edit → Topics → Enable so topics are turned on.
  3. Open Administrators → Add Admin → select your bot and turn on Manage Topics, Delete Messages (to remove closed cards’ topics), and Pin Messages (so each topic can silently pin its live status card and delete closed card topics cleanly).
  4. Open the group's General topic and send /linkforum. SUPER DESKTOP pins a live Dashboard in General and spawns one color-tagged topic per running card — with zero status-rename spam and automatic ✅ Done output reports as soon as a turn finishes.
4

PC Choose your permissions

By default, only Notifications and Redact common secrets start enabled. Turn on only the controls you want from Telegram — changes take effect immediately without restarting cards:

  • Enable Read terminal output to receive full ✅ Done result summaries, Waiting snippets, /screen, /history, /live, 📎 Files, and the Mini Web App terminal.
  • Enable Submit prompts and Control keys to reply directly from topics, approve prompts with Yes/No, or send interrupts.
5

Phone Open the Mini Web App or message any topic

  1. Turn on Tailscale on your phone (if using the Mini Web App below) and tap ⚡ Open App or send /app in your 1:1 bot chat.
  2. Or jump into your linked Forum group: tap any topic, reply directly to steer that harness, tap inline Quick Keys, or check /usage in General.
[04] ~/mini-appTAILSCALE SERVE · LIVE ANSI UI

OPTIONAL · PRIVATE TAILNET UI

Telegram Mini Web App via Tailscale.

Want a full Android-like experience right inside Telegram — live colored ANSI terminal over WebSocket, automatic live Omarchy theme syncing (dark & light), weekly allowance meters, swipeable Quick Keys, and interactive image/PDF/code previews? Serve the embedded UI on 127.0.0.1:7789 and wrap it privately inside your own Tailscale tailnet using tailscale serve (never public Funnel).

Use this prompt to setup

Paste this prompt into Claude Code, Codex, OpenCode, Antigravity, Grok, or any AI coding agent on your Linux PC to configure Tailscale Serve and enable the Mini Web App safely without exposing any tokens.

AI Agent Setup Prompt · tailscale serve + config.json 
Configure the SUPER DESKTOP Telegram Mini Web App on this Linux PC using Tailscale Serve (never Tailscale Funnel).

Rules:
- Never print, echo, or commit my bot token (`botToken`) or any secrets from config.json.
- Use `tailscale serve` (private to my tailnet only), never `tailscale funnel`.
- Keep all existing Telegram settings (`enabled`, `botToken`, `allowedUser`, `forum`, `permissions`) intact.

Steps:
1. Check Tailscale status with `tailscale status --json` and ensure it is Running with a `Self.DNSName`.
   - If MagicDNS or HTTPS Certificates are disabled, stop and tell me what toggle to enable in https://login.tailscale.com/admin/dns.
2. Expose only SUPER DESKTOP's local loopback Mini App server privately via Tailscale Serve:
   `tailscale serve --bg --https=8443 http://127.0.0.1:7789`
   and record `URL="https://<DNSName_without_trailing_dot>:8443"`.
3. Inspect `${XDG_STATE_HOME:-$HOME/.local/state}/super-desktop/telegram/config.json`:
   - If the Telegram bot is not yet configured (`enabled: false` or empty `botToken` or no `allowedUser`), stop and guide me through Settings → Telegram (`@BotFather` token + account pairing) first.
   - Otherwise update `config.json` atomically (`chmod 600`) to set:
     `miniApp.enabled = true`, `miniApp.listenPort = 7789`, `miniApp.publicUrl = "$URL"` (preserving `miniApp.shortName` and all other fields).
4. Signal/verify the worker cleanly:
   - Check `curl -fsS http://127.0.0.1:7789/health` and `curl -fsS "$URL/health"`.
   - If the `super-desktop telegram-bot` process isn't listening on `127.0.0.1:7789` yet, wait a couple seconds after updating `config.json` (the daemon hot-reloads it) or restart SUPER DESKTOP with `super-desktop status`.
5. Report back concisely:
   - The private Mini App `$URL`
   - Whether `/health` succeeded locally and via Tailscale HTTPS
   - Next steps on my phone (keep Tailscale ON, tap ⚡ Open App in 1:1 chat with the bot or run `/app`; optionally register `/newapp` in `@BotFather` and paste the short name into Settings → Telegram → Mini Web App for Forum Topic deep links).
M

Manual setup & optional @BotFather Forum Topic deep links

  1. Ensure MagicDNS and HTTPS Certificates are enabled in Tailscale Admin → DNS, and Tailscale is running on both your PC and your phone.
  2. Toggle Enable Telegram Mini Web App on in ⚙ Settings → Telegram, then click Auto-setup Tailscale Serve (or run tailscale serve --bg --https=8443 http://127.0.0.1:7789) and verify your https://<pc>.<tailnet>.ts.net:8443 URL saves cleanly.
  3. In your 1:1 chat with your bot, tap ⚡ Open App or send /app (works on Android, iOS, and Telegram Desktop while connected to your tailnet).
  4. Optional for Forum Topic buttons: Message @BotFather → /newapp, pick your bot, register a short name (e.g. superdesktop) pointing to your Tailscale Serve URL, and paste it in BotFather short name. Every card topic and ✅ Done report gains a 📱 Open App deep link directly to that card.
Multiple laptops & Linux servers? Telegram's Bot API allows only one active poller per bot token (sharing one token across two machines causes 409 Conflict). Simply create one @BotFather bot per machine (e.g. @sd_laptop_bot and @sd_server_bot) and group them — along with their Forum groups — into a single Telegram Chat Folder. Each machine runs independently with its own Tailscale Serve Mini App and its own live Omarchy theme.

[07] ~/securityBYOB TRUST MODEL

TRUST MODEL

Private control, honest limits.

Your bot, your PC, zero developer server: Bot credentials and state stay owner-only (0700/0600) on your Linux machine. Nobody else can pair without physical approval of a single-use invite + matching 6-digit code on your desktop, and any Forum group with more than 2 members is refused automatically.
Telegram Bot API is not end-to-end encrypted: Messages, images, and terminal output sent through a Telegram bot pass through Telegram's servers (and Telegram clients). Keep Redact common secrets enabled, leave unneeded switches off, and never send secrets to the chat. When you want direct device-to-device TLS with no third party at all, use the Android / iPhone / iPad app over LAN or Tailscale. Read the full Security model.

SymptomFix

Refused: this group has N members…Remove everyone except you and your bot so the group has at most 2 members, then run /linkforum again.
Promote this bot to Administrator…In Group Settings → Administrators, make the bot Admin with Manage Topics (and optionally Pin Messages).
Bot replies that an action is disabledEnable the corresponding switch under ⚙ Settings → Telegram → Permissions (for example Read terminal output for 📎 Files and /screen).

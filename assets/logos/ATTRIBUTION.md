# Toolbar logo sources

Company/product logos shown in the SUPER DESKTOP toolbar. All trademarks belong
to their respective owners; reused here purely as product identifiers.

| File | Brand | Source |
|---|---|---|
| `anthropic-black.svg`, `anthropic-white.svg` | Anthropic (Claude) | Simple Icons (`anthropic`), recolored white variant via cdn.simpleicons.org |
| `openai-black.svg`, `openai-white.svg` | OpenAI (Codex) | Wikimedia Commons `OpenAI logo 2025 (symbol).svg`, explicit fill added for light/dark variants |
| `grok-black.svg`, `grok-white.svg` | xAI (Grok) | Wikimedia Commons `Grok-feb-2025-logo.svg` (`currentColor` replaced) |
| `google.svg` | Google (Antigravity) | Wikimedia Commons multicolor "G" (Antigravity itself ships a wide wordmark lockup that is unreadable at toolbar size, so the Google mark is used) |
| `opencode-dark.svg`, `opencode-light.svg` | OpenCode (SST) | Official brand assets from sst/opencode (`packages/console/app/src/asset/brand/`) |
| `shell-black.svg`, `shell-white.svg` | Terminal (generic) | Hand-drawn `>_` glyph, no trademark involved |
